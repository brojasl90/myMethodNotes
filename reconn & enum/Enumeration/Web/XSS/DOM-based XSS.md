_DOM-based XSS_[3](https://portal.offsec.com/courses/pen-200/books-and-videos/modal/modules/introduction-to-web-application-attacks/cross-site-scripting/stored-vs-reflected-xss-theory#fn3) takes place solely within the page's _Document Object Model_ (DOM).[4](https://portal.offsec.com/courses/pen-200/books-and-videos/modal/modules/introduction-to-web-application-attacks/cross-site-scripting/stored-vs-reflected-xss-theory#fn4) While we won't cover too much detail for now, we should know that browsers parse a page's HTML content and then generate an internal DOM representation. This type of XSS occurs when a page's DOM is modified with user-controlled values. DOM-based XSS can be stored or reflected; the key is that DOM-based XSS attacks occur when a browser parses the page's content and inserted JavaScript is executed.
