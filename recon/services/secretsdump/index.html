    secretsdump

    secretsdump.py

    • Performs various techniques to dump secrets from the remote machine without executing any agent there.
    • Find cleartext credentials for another domain user.
    • DCSync replication can be performed using tools such as Mimikatz, Invoke-DCSync, and Impacket’s secretsdump.py.
