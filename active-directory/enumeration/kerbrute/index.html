    Kerbrute

    https://github.com/ropnop/kerbrute/releases/tag/v1.0.3

    A tool to quickly bruteforce and enumerate valid Active Directory accounts through Kerberos Pre-Authentication Grab the latest binaries from the releases page to get started.

    Download in my kali tools/kerbrute

    ./kerbrute_linux_amd64 userenum -d oscp.exam --dc 10.10.133.152 ../OSCP-C/MS01-153/users.txt
